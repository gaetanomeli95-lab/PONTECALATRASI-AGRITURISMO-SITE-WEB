# Agriturismo Ponte Calatrasi – sito web

Sito statico dell'Agriturismo Ponte Calatrasi (Roccamena, valle del Belice).

- `index.html`: tutta la pagina (stile, contenuti e animazioni)
- `assets/`: logo e fotografie

Librerie caricate da CDN: GSAP 3.12.5 con ScrollTrigger, Lenis 1.1.13. Font: Fraunces e Figtree da Google Fonts.

Per vederlo in locale basta servire la cartella, per esempio con `python3 -m http.server`.
